# Calendario

Aplicativo Vite/React do calendario operacional da barbearia.

## Desenvolvimento

```bash
npm install
npm run dev
```

Servidor local temporario: `http://localhost:3002/`.

## Observacoes

- A API sera integrada em uma etapa posterior.
- A autenticacao do dono tambem sera preparada depois.
- A variavel `VITE_CALENDAR_API_URL` fica reservada para a futura API do calendario.
